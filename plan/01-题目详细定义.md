## 一、项目介绍

《电动自行车安全技术规范》是电动自行车产品的强制性国家标准。**GB 17761—2024（发布 2024-12-31、实施 2025-09-01）已代替 GB 17761—2018**（2018 版 2018-05-15 发布、2019-04-15 实施，现状态**废止**；更早的 GB 17761—1999 亦已废止）。新国标对多项数值限值作了**实质性调整**：维持**最高设计车速不超过 25 km/h** 并**新增"超过 25 km/h 时电动机应停止提供动力输出"要求**；将**使用铅蓄电池的车型整车质量限值由 55 kg 放宽至 63 kg**；**新增"电动自行车使用的塑料的总质量不应超过整车质量的 5.5%"**；强化**防篡改**要求（电池组不得预留扩展车载电池接口或线路、控制器不得剪线跳线改装且不得兼容多种输入电压、限速器不得具备修改限速值功能等）。配套的**强制性**标准还有 **GB 43854—2024《电动自行车用锂离子蓄电池安全技术规范》**（发布 2024-04-25、实施 2024-11-01）与 **GB 42296—2022《电动自行车用充电器安全技术要求》**（发布 2022-12-29、实施 2023-07-01）。据官方问答，新国标设**生产过渡期至 2025-08-31、销售过渡期至 2025-11-30**（2025-09-01 起新生产车辆须符合新标准；2025-12-01 起所有销售产品须符合新标准）。

企业与监管侧的真实痛点是三条：**①参数易漏**——车型档案里车速、整车质量、塑料占比、电池电压/类型、防篡改设计等参数分散，逐项对照国标限值靠人翻标准必然漏项；**②换版易混**——2025-09-01 起适用新国标，但历史车型、库存车型、在研车型可能仍按 2018 版设计，混用即误判；**③依据无据**——送检/自查/抽检要"这个参数越没越限、依据哪条限值"，需要逐项挂标准条款与数值的确定性输出。

目前开源侧**"国标口径的电动自行车参数合规核查工具"近乎空白**（GitHub 检索 GB 17761 与"electric bicycle standard china"相关仓库数近乎为零）；商业侧为检测机构报告与企业内部 Excel 校验表，没有"版本化限值规则 + 参数矩阵 + 批量车型对账 + 证据指纹"的完整开源实现。

## 二、任务要求

> 首期范围限定为 **GB 17761—2024 整车安全技术规范主要限值 + GB 43854—2024 锂电池 + GB 42296—2022 充电器** 三份强制标准的可参数化条款，并以 GB 17761—2018 用于历史车型对照；电磁兼容、材料阻燃等纯试验方法条款留扩展。全部模块遵循"**未挂原文核对不得落库/生效/进入核查路径**"的确定性纪律。

### 1）整车参数限值矩阵引擎（确定性内核，亮点）

- 把 GB 17761—2024 的可参数化条款编码为**结构化限值规则**（参数名、限值、比较方向、适用条件、条款依据）；
- 输入车型参数档案（最高设计车速、整车质量、蓄电池类型、塑料总质量占比、标称电压、电动机额定功率、防篡改设计项、脚踏骑行装置等），**确定性判定**每项参数是否越限；
- 输出 **符合 / 不符合 / 不适用 / 未提供（不可判定）** 四态 + 条款依据（结论旁挂标准号与条款号），**"未提供参数"绝不判为符合**；
- 限值与适用条件一律从规则包读取，**禁止硬编码**。

### 2）蓄电池与充电器专项核查（多标准联动，亮点）

- **GB 43854—2024**（锂电池）：按可参数化条款核查电池类型识别、输出电压限值等；
- **GB 42296—2022**（充电器）：按可参数化条款核查充电器基本安全参数项；
- 输出跨三份标准的**统一核查结论**，每项挂对应标准号与条款依据；
- 三份标准为**独立来源**（各有发布/实施日期与标准号），规则包分册组织、互不混用。

### 3）双版本规则集与差异对照器（工程亮点）

- 规则包按 **`标准 × 版本`** 组织：`GB 17761—2018` 与 `GB 17761—2024` 各成独立规则集，限值逐条独立挂来源；
- **版本差异报告**：一键列出两版在整车质量（55 kg→铅蓄电池车型 63 kg）、塑料占比（新增 5.5%）、超速断电（新增要求）、防篡改条款等方面的**实质差异**；
- **按车型设计年份/上市年份锚定版本**（2025-09-01 前后、过渡期生产/销售窗口分别适用对应口径），杜绝"用新国标重判旧车型"；
- 每条规则挂 `status`（`verified`/`pending`），**未核对不得进入核查路径**。

### 4）车型清单批量扫描与对账（M3 级，批量扫描对账）

- 支持目录/清单批量读入**多企业 × 多车型 × 多批次**车型参数表，逐款核查，**失败件隔离不中断**（坏格式、缺字段、参数不可解析单列原因码）；
- **跨轮对账**：本轮核查与上轮比对，输出"新增越限 / 已整改 / 持续越限"三集合；
- **字段映射引擎**：车型参数表列名千差万别（"最高车速"/"最高设计车速"/"设计车速"），映射到标准参数名后方可核查，映射不确定即标 `未提供`，**绝不臆测**。

### 5）内置评测基准（零 API 依赖）

- **限值边界基准**：各参数限值的边界值（恰好等于限值、上下最小计量单位）枚举验证判定正确性（如车速 25.0 / 25.1 km/h、塑料占比 5.5%）；
- **版本对照基准**：同一车型参数在两版规则下的期望结论差异，验证版本切换；
- **合成车型档案基准**：程序化构造带植入真值的合成车型（如"某铅蓄电池车型整车质量 62 kg"应判符合、"某车型塑料占比 6.2%"应判不符合），零 API 依赖可重复，指标口径写进 README；
- **误报对照集**：显式声明"应零命中"的干净档案（全参数达标）与"应降级"的档案（单位口径可显式换算 → 只报 `warning`），基准层只读声明、不自选考卷。

### 6）证据链与报告导出（可核证交付物）

- 每个核查结论可挂**证据**（本地文件引用与指纹），车型档案与结果整体计算 **sha256 指纹**随底稿固化；
- 一键导出**合规核查报告**（Markdown + XLSX）：含车型清单、逐款逐参数结论与条款依据、越限项与整改建议、版本坐标与证据指纹；
- 报告头固定输出**规则包坐标**（标准版本 + 版本号 + 生成时间）。

### 7）桌面与 CLI 双形态

- 同一套引擎既有命令行、也有桌面界面；**界面只渲染引擎结果、零判定逻辑**（GUI 服务层是唯一引擎调用点，保证界面与 CLI 结论一致）。

## 六、边界与非目标

- **不做**：不做实物检测或试验（不替代检测机构）；不做产品认证受理或 CCC 发证判定；不做道路通行/上牌/交管规则判定；不做电池管理系统（BMS）软件分析；不对接监管申报接口。
- **首期范围**：GB 17761—2024 主要可参数化限值 + GB 43854—2024 + GB 42296—2022；以 GB 17761—2018 用于历史车型对照；纯试验方法条款与电磁兼容等留扩展。
- **合规红线**：**全本地处理存储、零上传**；车型参数与供应链信息可能含商业敏感信息，工具默认不联网；**免责声明强制**：输出为基于标准限值的合规检查发现，不构成产品合格判定、检测结论或行政认定，正式结论以具备资质的检验检测机构报告与市场监管部门口径为准；规则包未挂原文核对（`status=pending`）不得进入核查路径。
- **数据纪律**：演示与基准一律使用**合成车型档案**，禁止真实企业车型参数入库；合成企业统一使用虚构名称与测试号段（统一社会信用代码 `90000000…SYN`、车型代号样例 `SYN-…`），按白名单登记；证据样本仅留结构说明。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
